01 — About

About Me

My journey into cybersecurity and what drives me

I'm an aspiring SOC Analyst passionate about transforming security theory into practical defense mechanisms. My journey into cybersecurity began with a fascination for how networks communicate — and how threats can be detected at the packet level.

My focus areas include network packet analysis, threat detection, and security awareness training. I believe effective cybersecurity requires both technical expertise and the ability to educate users about social engineering and phishing risks.

My approach combines hands-on, project-based learning with theoretical knowledge. From building network packet sniffers with Python and Scapy to creating an interactive phishing awareness platform, I focus on security solutions that make a tangible difference.

My career goal is to contribute to proactive threat hunting and incident response teams, where I can apply an analytical mindset and a continuous learning attitude to protect organizations from evolving cyber threats.

Network Packet Sniffer

A real-time network packet analysis tool built with Python and Scapy that captures and decodes traffic across multiple protocol layers. The project demonstrates a fundamental understanding of network architecture and packet-level threat detection.

Problem

Limited visibility into raw network traffic makes packet-level threat detection and anomaly identification difficult.

Outcome

A multi-layer packet analyzer covering Ethernet MAC, IP, TCP, UDP, and ICMP, with a CLI for real-time traffic monitoring.

Technical Implementation

  • Python 3.8+ with the Scapy library
  • Ethernet, IP, TCP, UDP, and ICMP packet dissection
  • Customizable CLI parameters (-i interface, -c packet count)
  • Loopback testing plus live internet traffic capture
  • Formatted real-time output of source/destination addresses, ports, and protocols

SOC Analyst Relevance

  • Raw traffic analysis that underpins SIEM log analysis
  • Practical understanding of OSI model layers and protocol behavior
  • Foundation for custom detection rules and anomaly identification
  • Hands-on packet-level forensics experience

Key Learning Outcomes

Protocol dissection Real-time monitoring Security CLI tooling

View repository
HTML CSS JavaScript Security Awareness

Phishing Awareness Training Platform

An interactive, zero-dependency web-based training module that teaches users to recognize phishing attacks and social engineering tactics. It features four comprehensive learning modules with interactive elements and assessment capabilities.

Problem

Users often lack the practical knowledge needed to identify phishing messages and social engineering attempts.

Outcome

Four learning modules, 20+ assessment questions, XSS prevention, a strict Content Security Policy, and persisted progress tracking.

Technical Implementation

  • Pure HTML, CSS, and JavaScript — no frameworks or dependencies
  • Modules covering email anatomy, fake website detection, social engineering psychology, and defensive best practices
  • Click-to-reveal hotspots, a URL breakdown analyzer, and scenario-based decisions
  • Assessment center with immediate feedback and score tracking
  • Progress persistence using safe localStorage practices
  • Security-first coding: input sanitization, XSS prevention, and strict CSP

SOC Analyst Relevance

  • Understanding social engineering attack vectors for threat intelligence
  • Translating technical concepts into effective user-facing training
  • Secure coding practices essential for security-minded development
  • Attack pattern recognition and user behavior analysis

Key Learning Outcomes

Social engineering ID Secure web development Program design Behavioral change
